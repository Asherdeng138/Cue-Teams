## English

Save **live captions already generated by the Microsoft Teams desktop client** to local TXT and JSON files, with the speaker labels exposed by Teams. No browser extension or additional speech recognition is needed.

This community derivative focuses on Teams caption saving and is based on [Digitalgrub's Cue / meeting-copilot](https://github.com/Digitalgrub-Org/meeting-copilot) **v1.2.3**. It is not an official Microsoft or Digitalgrub product. The original MIT license and copyright notice remain in [LICENSE](LICENSE); see [ATTRIBUTION.md](ATTRIBUTION.md) for provenance and changes.

### Download and start

For **Windows 10 / 11 x64**: [download the portable ZIP](https://github.com/Asherdeng138/Cue-Teams/releases/latest/download/Cue-Teams-Windows-x64.zip), choose **Extract All**, open the extracted `Cue-Teams` folder, and double-click `CueTeams.exe`.

No Python, Ollama, or browser extension installation is required. Keep the entire folder, including `_internal`. Enable live captions in your Teams desktop meeting before starting capture. The application UI is currently in Simplified Chinese; this README provides instructions in both languages. GitHub's automatic **Source code** downloads are for developers; choose the Windows portable ZIP to run the app directly.

### Features

- Read Teams desktop meeting captions through Windows UI Automation, with automatic meeting-window detection and manual window selection.
- Pair speaker labels with caption text within each caption row; preserve commas, parentheses, and Unicode names. Missing names appear as “未识别发言人” (unidentified speaker).
- Update evolving text in the same caption row and retain identical short replies from different speakers.
- Show distinct waiting, read-error, save-error, and saved states.
- Automatically save TXT / JSON. Edit the file name and choose the save folder from the main window; the folder preference is remembered.
- Apply a new name or folder during capture while retaining previous files. Existing names receive a numbered suffix.
- Use a light interface with rounded controls, scrolling, keyboard shortcuts, and TXT-copy export.

The Teams entry point offers no audio recording, AI summarization, or cloud processing, and requires no API key or running Ollama service. Some upstream Cue modules remain as import dependencies. Running `live_capture.py` directly opens the original full entry point; use `teams_app.py` for this edition.

### Requirements

- Windows 10 / 11 x64 and the Microsoft Teams desktop client.
- A Teams meeting with live captions available. Keep the caption panel expanded and the meeting window accessible.
- To run from source: Python 3.12 with Tcl/Tk is recommended, together with Windows PowerShell 5.1 and the dependencies below.
- Writable application and recording folders. Organization policies, Teams versions, and accessibility-tree changes can affect capture.

### Run from source

Download or clone this repository, then open PowerShell in the repository root:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-teams-lock.txt
.\.venv\Scripts\python.exe teams_app.py
```

The lock file records the tested environment, including test and build tools. AI SDKs are retained import dependencies of upstream modules; the Teams entry point does not initiate AI calls.

### Usage

1. Enable live captions in your Teams desktop meeting and keep the caption panel expanded.
2. Open the app, enter a name under **会议 / 文件名** (meeting / file name), and choose a save folder.
3. Click **开始保存字幕** (start saving captions). If automatic selection fails, choose the actual meeting window in the dropdown.
4. **Check that names and captions appear and the 已保存 (saved) count increases.** Clicking Start alone does not confirm successful capture.
5. Click **停止保存字幕** (stop saving captions) after the meeting. Find the TXT / JSON files in your selected folder.

Shortcuts: `Ctrl+R` starts / stops capture; `Ctrl+S` exports a TXT copy. After changing the name or folder during capture, click **应用更改** (apply changes). Previous files are retained.

By default, the first run creates `data/` and `字幕记录/` beside the program. `CUE_DATA_DIR` and `CUE_RECORDINGS_DIR` can override the initial directories; a folder preference saved in the UI takes priority over the initial recordings directory. If the configured data directory is unwritable, the configuration module may fall back to `.meeting_workflow/` in the user's home directory. Choose a writable location for the program.

TXT files use UTF-8 with `Speaker: caption` entries. JSON stores captions captured by this app; it is not an official Teams recording or a transcript export with precise speech timestamps.

### Troubleshooting and limitations

- **Blank view or 等待字幕 (waiting for captions):** check that Teams itself shows captions, the selected window is the meeting, and the caption panel is expanded. The Help menu offers the latest reader diagnostic.
- **Text without a name:** only labels exposed by Teams can be used. Hidden identities, shared microphones, and individual people behind meeting-room devices cannot be reconstructed.
- Capture begins when you start the app's saving session. Previously displayed captions that have disappeared cannot be recovered.
- Reading uses polling. Fast scrolling, hidden / minimized windows, or Teams UI updates may cause missed captions; permanent compatibility or zero omissions cannot be guaranteed.
- Regression checks cover synthetic caption trees, real Tk controls, name pairing, deduplication, save paths, and error states. **A real multi-participant Teams meeting still needs end-to-end validation for this revision.**

### Tests

Run tests in a Windows desktop session; Tk GUI tests need an available display. This public package includes caption-related regression tests with synthetic / illustrative identities and text, not real meeting recordings.

```powershell
$env:CUE_DATA_DIR = Join-Path $env:TEMP ('cue-test-data-' + [guid]::NewGuid())
$env:CUE_RECORDINGS_DIR = Join-Path $env:TEMP ('cue-test-recordings-' + [guid]::NewGuid())
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe teams_app.py --self-test
```

The self-test writes synthetic caption files, so retain the isolated environment variables above. Close that PowerShell window afterward to keep those overrides out of normal use. The GitHub Actions Windows workflow runs these checks too. Before publishing, run:

```powershell
.\.venv\Scripts\python.exe scripts/check_public_source.py
```

A Windows desktop tool that saves Microsoft Teams' own live captions locally, with the speaker labels exposed by Teams.

这是基于 [Digitalgrub 的 Cue / meeting-copilot](https://github.com/Digitalgrub-Org/meeting-copilot) **v1.2.3** 开发的社区衍生版本，专注 Teams 字幕保存。不是 Microsoft 或 Digitalgrub 发布的官方产品。原作者的 MIT 许可证及版权声明完整保留于 [LICENSE](LICENSE)，来源提交及改动说明见 [ATTRIBUTION.md](ATTRIBUTION.md)。

### 功能

- 使用 Windows UI Automation 读取 Teams 桌面会议字幕；自动寻找会议窗口，也可手动指定。
- 按字幕行关联发言人与正文，保留逗号、括号和中文姓名；姓名缺失时明确显示“未识别发言人”。
- 更新同一字幕行中逐步完善的句子，保留不同发言人的相同短句。
- 明确显示等待字幕、读取失败、保存失败与已保存状态。
- 自动保存 TXT / JSON；主界面可修改文件名、选择保存目录，并记住目录。
- 采集中可应用新名称和目录，保留原文件；遇到已有名称自动添加序号。
- 浅色圆角界面，支持滚动、快捷键和导出 TXT 副本。

本入口不提供录音、AI 摘要或云端处理；不需要配置 API Key 或启动 Ollama。部分原 Cue 模块仍作为导入依赖保留，直接运行 `live_capture.py` 会进入原有完整入口，不属于此版本的推荐用法。

### 环境

- Windows 10 / 11，Microsoft Teams 桌面客户端。
- Teams 会议能显示实时字幕；保持字幕面板展开且会议窗口可访问。
- 从源码运行：建议 Python 3.12（含 Tcl/Tk）、Windows PowerShell 5.1，以及下列依赖。
- 选择可写的程序和记录目录。组织策略、Teams 界面版本及辅助功能树可能影响读取。

下载本仓库源码或克隆后，在仓库根目录打开 PowerShell：

py -3.12 -m venv .venv

### 使用

1. 在 Teams 桌面会议中开启实时字幕，保持字幕面板展开。
2. 打开本程序，在主界面填写“会议 / 文件名”并选择保存文件夹。
3. 点击“开始保存字幕”；自动选择失败时，从下拉列表选择真正的会议窗口。
4. **确认正文出现姓名与字幕，且“已保存”计数增长**。仅点击开始不代表已采集成功。
5. 会后点击“停止保存字幕”，从所选文件夹查看 TXT / JSON。

快捷键：`Ctrl+R` 开始 / 停止，`Ctrl+S` 导出 TXT 副本。采集中更改名称或目录后，点击“应用更改”；此前的文件保留。

首次运行默认在程序目录创建 `data/` 和 `字幕记录/`，也可以用 `CUE_DATA_DIR`、`CUE_RECORDINGS_DIR` 指定初始目录。界面中已保存的目录偏好优先于初始记录目录。配置模块在指定数据目录不可写时可能回退到用户目录下的 `.meeting_workflow/`；避免将程序放进只读目录。

TXT 使用 UTF-8，内容格式为 `发言人: 字幕`。JSON 保存本程序采集到的字幕条目；不是 Teams 官方录制或带精确语音时间轴的转录导出。

### 故障排查与限制

- 空白或“等待字幕”：检查 Teams 自己是否已经出现字幕，选中的是否为会议窗口，字幕区域是否展开。帮助菜单可查看最近读取诊断。
- 只有正文没有姓名：本程序只使用 Teams 暴露的姓名，无法恢复隐藏身份、共享麦克风或会议室设备背后的实际个人。
- 本程序只保存开始采集后读到的字幕，不能恢复此前已经消失的内容。
- 读取使用轮询。字幕滚动过快、窗口隐藏 / 最小化或 Teams 更新都可能造成漏采；不能保证永久兼容或零遗漏。
- 合成字幕树、真实 Tk 控件、姓名配对、去重、保存路径和错误状态已有回归验证；**当前修订版仍需要在真实多人会议中完成端到端验收**。
